# Mini E-commerce Product Guide Chatbot

A low-code chatbot project built for the **Low-Code Chatbot Deployment Exercise**.  
This chatbot helps users discover products based on category and budget, then guides them toward product details and purchase options.

🔗** Live Demo:**
https://ashishsrs01.github.io/Mini-E-commerce-guide-chatbot/

## Project Overview

This project is a **Mini E-commerce Product Guide Bot** created using **WotNot** and embedded into a static webpage hosted on **GitHub Pages**.

The chatbot flow is designed to be simple, interactive, and suitable for a classroom/demo submission:
- Welcome message
- Category selection
- Budget selection
- Product recommendations
- View details / Buy now actions
- Email capture for offers or follow-up

## Features

- Category-based product suggestions
- Budget filtering
- Static product recommendations
- Embedded chatbot widget
- Clean landing page interface
- GitHub Pages deployment
- Responsive and presentation-friendly layout

## Tech Stack

- **Chatbot Platform:** WotNot
- **Frontend:** HTML, CSS
- **Hosting:** GitHub Pages
- **Embedding:** WotNot iframe embed

## Chatbot Flow

1. **Welcome**
   - Greets the user
   - Introduces the chatbot

2. **Choose Category**
   - Shoes
   - Phones
   - Laptops

3. **Choose Budget**
   - Under ₹10,000
   - ₹10,000 – ₹30,000
   - Above ₹30,000

4. **Show Product Suggestions**
   - Displays 2–3 static product options

5. **User Action**
   - View Details
   - Buy Now
   - Go Back

6. **Email Capture**
   - Collects email for offers or follow-up

7. **Final Message**
   - Thanks the user and ends the flow

## Deployment

This project is deployed on **GitHub Pages** as a static website.

### Steps Used
1. Created the chatbot flow in WotNot
2. Copied the WotNot embed iframe code
3. Added the iframe into a custom HTML page
4. Uploaded the project to GitHub
5. Enabled GitHub Pages from the repository settings
